# 报错不是你错了

> 新手最怕红色报错，老手最爱红色报错。这一课改变你和报错的关系 —— 它是免费的、24 小时在线的、脾气极好的家教。

## 先建立一个正确的心态

看到报错时，新手的常见反应是：「完了，我弄坏了」。

但报错的真相是：

> **Python 拒绝执行一段它没理解的代码，并且认真告诉你它哪里没理解、在第几行。**

它不是在批评你，它是在**帮你避免一个更糟的结果** —— 比如把错误的计算结果写进数据库，或者让程序在你不知道的地方悄悄跑偏。

一个残酷的事实：**报错越早越好，报错信息越详细越好。** 最可怕的程序是那种"不报错，但结果不对"的。

## 怎么读报错：从最后一行开始

这是最实用的一条技巧，能省掉你未来无数时间。

看这个例子：

```python
print("你好"
```

运行它会得到一段红色的东西：

```
File "<exec>", line 1
    print("你好"
                ^
SyntaxError: '(' was never closed
```

信息很多，但**你只需要看最后一行**：

```
SyntaxError: '(' was never closed
```

翻译：「语法错误：有个左括号一直没被关上。」

再看倒数第二部分的 `line 1` —— 告诉你问题在第 1 行。

**读报错的标准姿势：**
1. 跳到最后一行 → 知道**是什么错**
2. 往上找 `line N` → 知道**在哪一行**
3. 回到那一行 → 修

## 四种你会遇到 100 次的错误

### 1. SyntaxError —— 语法错误（话说得不合规矩）

最常见的三种原因：

**括号没配对：**

```python
print("你好"
```

报错：`SyntaxError: '(' was never closed`

**引号没配对：**

```python
print("你好)
```

报错：`SyntaxError: unterminated string literal`（字符串没结束）

**⚠️ 用了中文标点：** 这个坑几乎每个中国新手都踩过。

```python
print（"你好"）   # 这里的括号是全角中文括号 （ ）
print("你好"）；  # 这里的分号是中文分号 ；
```

报错同样是 `SyntaxError`，但你可能盯着屏幕看十分钟都看不出哪里不对 —— 因为中文括号 `（` 和英文括号 `(` 长得太像了。

**判断方法**：中文标点通常更宽、占两个字符位置。输入代码时，**确保输入法处于英文状态**（看输入法状态栏是不是显示"英"或"EN"）。

### 2. NameError —— 名字不存在

```python
print(massage)
```

报错：`NameError: name 'massage' is not defined`

意思是：我要打印 `massage` 这个东西，但我从没见过它。

两种最常见的原因：

- **忘了加引号**：你想打印文字 "massage"，却写成了 `print(massage)`，Python 以为它是个变量名
- **拼写不一致**：前面写的是 `message = "hi"`，后面打成了 `massage`

### 3. IndentationError —— 缩进不对

```python
print("第一行")
    print("第二行")
```

报错：`IndentationError: unexpected indent`

Python 用**行首的空格**来表示代码的层级关系（这在后面的 if、循环里会大量使用）。所以不该缩进的地方乱缩进，它就懵了。

现阶段记住一条：**同一段代码里，每一行都从最左边开始写，不要乱加空格。**

### 4. TypeError —— 类型不对

```python
print("距离：" + 100)
```

报错：`TypeError: can only concatenate str (not "int") to str`

翻译：「我只能把字符串和字符串拼接，不能把字符串和数字拼一起。」

这个错误在后面讲数据类型时会经常遇到，现在先混个脸熟。

## 遇到报错的四步处理法

把它变成习惯，你会比 90% 的新手走得快：

**第一步：读最后一行。** 知道错误类型。

**第二步：找行号。** 定位到具体那一行。

**第三步：如果看不懂，复制最后一行去搜索。** 
直接把 `SyntaxError: '(' was never closed` 粘到搜索引擎里，几乎 100% 能找到答案。这是程序员每天都在做的事，不丢人。

**第四步：还不行，就把代码删到只剩一行，再加回来。**
这是终极手段。注释掉一半代码，看还报不报错 —— 不报了，说明错误在被注释掉的那一半里。反复二分，几分钟就能定位。

## 一个重要的心理建设

> 职业程序员每天也会制造几十个报错。
> 他们的优势不是"不犯错"，而是"看到报错不慌，30 秒就能定位"。

你现在每遇到的一个报错，都是在给未来的自己攒经验值。
