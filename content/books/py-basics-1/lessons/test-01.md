## 第一部分 · 选择题

检验这章的概念有没有真正记住。

```quiz
type: choice
q: 下面这段代码的运行结果是什么？
  print("苹果", "香蕉", sep="-")
options:
- 苹果-香蕉
- 苹果 香蕉
- 苹果-香蕉-
- 报错
answer: 0
explain: sep 参数控制"多个内容之间用什么隔开"。这里指定用 -，所以输出 苹果-香蕉。如果不写 sep，默认用空格隔开。
```

```quiz
type: choice
q: 为什么 print(你好) 会报错，而 print("你好") 不会？
options:
- 因为中文不能直接打印
- 因为不加引号时，Python 会把"你好"当成一个变量名去找它，找不到就报 NameError
- 因为 print 函数规定必须加引号
- 因为引号能让文字显示得更清楚
answer: 1
explain: 引号的作用是划界：引号里面是"数据"（纯文字），外面是"代码"（命令或名字）。不加引号，Python 就以为你在说一个叫"你好"的变量。
```

```quiz
type: choice
q: 关于注释，下面哪种做法是「好注释」？
options:
- print("你好")  # 打印"你好"
- # 这里必须用 0.1，因为上游接口只认浮点数
- 每一行代码后面都加一句解释它在干嘛
- 把不想执行的代码删掉，而不是注释掉
answer: 1
explain: 代码本身已经说明了"做了什么"，注释应该补充代码里写不出来的"为什么"。复述代码的注释是废话；而"删掉"是不可逆的，调试时注释掉更好。
```

```quiz
type: choice
q: 看到一段报错，最有效率的阅读顺序是？
options:
- 从上往下逐行读，一个字不能漏
- 先读最后一行（错误类型），再找 line N（出错位置）
- 只看红色的字
- 复制到翻译软件里翻译一遍
answer: 1
explain: 最后一行告诉你"是什么错"，line N 告诉你"在哪一行"。这两条信息组合起来，90% 的报错都能在 30 秒内定位。
```

```quiz
type: choice
q: 代码 print（"你好"） 报错的最可能原因是？
options:
- print 拼错了
- 用了中文的全角括号 （ ） 而不是英文括号 ( )
- 引号用错了
- Python 不支持打印中文
answer: 1
explain: 中文全角括号和英文括号长得极像，但 Python 只认英文的那个。写代码时保持输入法在英文状态，能避开这个几乎人人踩过的坑。
```

## 第二部分 · 算法题

不只是"会用"，还要"想得明白"。

```quiz
type: code
q: 只用一个 print，输出下面这个由星号组成的三角形
starter: |
  # 目标图案：
  # *
  # **
  # ***
  # ****
  # *****
  #
  # 提示：字符串也能做乘法！
  #   "*" * 3  的结果是  "***"
  #   "ab" * 2 的结果是  "abab"
  #
  # 提示2：可以用 \n 把 5 行拼成一个字符串，再一次性 print
  
  print("先从这里开始改")
tests:
- assert __out.count("\n") >= 4
- assert __out.strip().split("\n")[0].strip() == "*"
- assert "***" in __out
hint: 试试先单独运行 print("*" * 3) 看看效果。然后想办法把 5 个不同长度的星号串，用 \n 连成一个大字符串。
explain: 字符串乘法 "*" * n 能快速造出 n 个星号，这是 Python 里很讨巧的特性。你当然也可以写 5 行 print —— 但用"字符串乘法 + \n 拼接"的思路，是在训练把重复规律抽象出来的能力，这正是算法思维的核心。
```

```quiz
type: code
q: 修复这段"坏掉的名片程序"，让它正确输出 4 行内容
starter: |
  # 这段程序有 3 个错误，全部找出来并修好
  print("姓名：张三"
  print(爱好：编程)
  # print("城市：杭州"
  print("口号：每天进步一点点")
tests:
- assert "姓名：张三" in __out
- assert "爱好：编程" in __out
- assert "城市：杭州" in __out
hint: 三个错误分别是：第 1 行少右括号、第 2 行"爱好：编程"没加引号、第 3 行整行被注释掉了。逐个修。
explain: 这三个错误正好对应本章的三种典型坑：括号不配对（SyntaxError）、字符串忘加引号（NameError）、整行被注释掉（代码不执行）。能一次找全，说明这一章你真的掌握了。
```

## 第三部分 · 小项目

把这一章的东西做成一件"拿得出手"的完整作品。

```quiz
type: project
q: 制作一张「我的个人名片」—— 用 print 在屏幕上输出一张有边框的卡片
checklist:
- 至少输出 5 行（含边框）
- 用了 ─ │ ╭ ╮ ╰ ╯ 或 * = - 之类的字符做出边框，卡片有"形状"
- 卡片内容是真实的你自己（昵称、在学什么、一句签名等）
- 每行都从最左边开始，没有多余的缩进（否则会 IndentationError）
- 代码里至少写了 1 行注释，说明你为什么这么排版
- 点过「运行」，确认真的能跑出你想要的图案
hint: 先在纸上画出卡片的样子，再照着用 print 一行一行"画"出来。边框只是字符串，别想复杂了。
explain: 这个项目考察的是"把想法翻译成代码"的完整流程 —— 先在脑子里（或纸上）想清楚成品长什么样，再拆解成一行行的输出。这就是编程的真实工作方式。
```

## 这一章，你学会了什么

- ✅ 编程的本质：把事情拆成**无歧义的有序步骤**
- ✅ Python 是**解释型**语言，需要一个解释器才能跑
- ✅ `print` 的用法：`sep`、`end`、`\n` 转义
- ✅ 引号的作用是**划界**：里面是数据，外面是代码
- ✅ 注释写**"为什么"**，而不是复述"做了什么"
- ✅ 读报错先看**最后一行**，再找**行号**
