# 第一个程序

> 终于要写代码了。这一课只讲一个东西 —— `print`。但我会把它拆得足够细，让你明白每一对括号、每一个引号都是干嘛的。

## 最小的一个程序

```python
print("你好，世界")
```

点「▶ 运行」，屏幕上会出现：

```
你好，世界
```

就这么简单。但别急着往前走 —— 这行代码里有 **4 个部分**，每一个都不能少：

```
print( "你好，世界" )
  ↑     ↑           ↑
  │     │           └─ 右括号：话说到这里结束
  │     └───────────── 内容：你想说的话
  └─────────────────── 动作：打印
```

拆开说：

1. **`print`** —— 一个"动作的名字"。Python 内置了几百个这样的现成动作，`print` 的意思是「把内容显示到屏幕上」。
2. **`(` 和 `)`** —— 括号表示「把东西交给这个动作」。就像 `递给(小明, 一本书)` 里的括号，说明"书"是给"小明"的。
3. **`"你好，世界"`** —— 内容本身。被引号包起来的文字，在编程里有个专门的名字：**字符串（string）**。

## 为什么内容必须加引号？

这是新手最常问的问题，也是理解编程思维的第一道坎。

想一下：如果不加引号，写成

```python
print(你好)
```

Python 会怎么想？它会以为「你好」是一个**名字**（比如一个人的名字、一个变量），然后去找"叫你好的那个东西"是什么。找不到，就报错。

加上引号，等于告诉 Python：

> 「这不是命令，也不是名字，这就是一段**纯粹的文字**，原样显示出来就好。」

**引号的作用就是划界：引号里面是"数据"，引号外面是"代码"。**

### 单引号还是双引号？

两个都能用，效果完全一样：

```python
print("你好")   # 双引号
print('你好')   # 单引号
```

那什么时候必须用某一个？内容里本身就含引号的时候：

```python
print("他说："你好"")     # ❌ 这样会出错，Python 分不清哪对引号是边界
print("他说：'你好'")      # ✅ 外层双引号，内层单引号
print('他说："你好"')      # ✅ 反过来也行
```

规律很简单：**外层用什么，里面就别用什么。**

## 一次打印好几样东西

用逗号隔开：

```python
print("苹果", "香蕉", "橙子")
```

输出：

```
苹果 香蕉 橙子
```

注意中间那个空格 —— 是 `print` 自动加的。这个"自动加的东西"其实可以改：

```python
print("苹果", "香蕉", "橙子", sep="、")
```

输出：

```
苹果、香蕉、橙子
```

`sep` 是 separator（分隔符）的缩写，意思是「用顿号把几样东西隔开，不要用空格」。

再看一个更有用的参数 `end` —— 它控制"打印完之后加什么"。默认每次 `print` 结束时会自动换行，所以两次 print 才会分成两行：

```python
print("第一行")
print("第二行")
```

如果不想换行：

```python
print("加载中", end="")
print("...")
```

输出：`加载中...`（挤在一行里）

这个小技巧在做进度条、加载动画时特别有用。

## 想换行、想缩进怎么办？

在字符串里写 `\n` 表示换行，`\t` 表示缩进（Tab）：

```python
print("第一行\n第二行\n第三行")
```

输出：

```
第一行
第二行
第三行
```

那个反斜杠 `\` 叫**转义字符** —— 它的意思是「后面这个字符不当普通字符看，当特殊指令看」。

常用的就这几个：

| 写法 | 效果 |
|---|---|
| `\n` | 换行 |
| `\t` | 一个 Tab 缩进 |
| `\\` | 一个真正的反斜杠（`\` 自己要转义） |
| `\"` | 一个真正的双引号 |

## 程序是从上往下一行一行跑的

这个"理所当然"的规则，值得单独强调，因为后面所有的复杂逻辑都建立在它之上：

```python
print("先做这个")
print("再做这个")
print("最后做这个")
```

输出顺序和你写的顺序**完全一致**。没有例外。

所谓"编程"，很大程度上就是在**安排行的顺序**。

## 小测验 · 打印一首三行的小诗

把上面学的串起来：用**一次** `print` 调用，输出三行内容。

要求最终输出是这样：

```
床前明月光
疑是地上霜
举头望明月
```

```quiz
type: code
q: 只用一个 print，配合 \n 输出上面那三行（引号里的内容自己决定，能输出三行就行）
starter: |
  # 只用一个 print，在三行内容之间用 \n 隔开
  print("第一行\n第二行\n第三行")
tests:
- assert __out.count("\n") >= 2
hint: \n 要写在同一个字符串里面，而不是分成三次 print。把示例里的"第一行/第二行/第三行"换成诗的内容。
explain: __out.count("\n") >= 2 是在数输出里有几个换行符 —— 三行内容需要两个换行。这也是测试代码常用的思路：不比较整段文字，而是检查关键特征。
```

> 如果你用了三次 `print` 也做出来了 —— 那也对，但请再试一次「一次 print + `\n`」的写法。两种方法你都应该会。
